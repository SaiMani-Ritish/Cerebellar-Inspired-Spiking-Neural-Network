Track A deep dive: LIF neurons and STDP
The LIF (Leaky Integrate-and-Fire) neuron is your fundamental building block. Here's exactly what you need to understand and how to learn it:

Concept	What it means	How to learn it	Why it matters for your work
LIF neuron	Membrane voltage leaks over time. When it crosses a threshold, it fires a spike and resets	snnTorch tutorial, change β (decay rate) from 0.5 to 0.9 and watch what changes	Your entire controller is built from these. Understanding τ and β lets you tune responsiveness
Surrogate gradient	Spikes are non-differentiable, so we use a smooth approximation (like a sigmoid) for backprop	Read snnTorch's training tutorial. The key function is FastSigmoid	This is how you train your hidden LIF layers before adding STDP. Required for Phase 2

The event encoding function — implement this in Week 3
data.py · event encoding
def velocity_to_spikes(v, threshold=0.1):
    """
    Convert continuous cart velocity to a 2-bit spike event.
    ON event  [1, 0]: velocity exceeded positive threshold
    OFF event [0, 1]: velocity exceeded negative threshold
    No event  [0, 0]: velocity in dead zone
    
    This is your bridge from continuous physics to discrete spikes.
    The threshold value is a hyperparameter — tune it in Phase 2.
    """
    if v > threshold:
        return [1, 0]   # ON event
    elif v < -threshold:
        return [0, 1]   # OFF event
    else:
        return [0, 0]   # no event (dead zone)

def state_to_spikes(obs, thresholds=None):
    """
    Full cart-pole state [pos, vel, angle, angular_vel] → spike vector.
    Apply velocity_to_spikes independently to each relevant dimension.
    """
    if thresholds is None:
        thresholds = [0.05, 0.1, 0.02, 0.1]
    spikes = []
    for val, thr in zip(obs, thresholds):
        spikes.extend(velocity_to_spikes(val, thr))
    return spikes   # 8-dimensional spike vector

Track C: Polynomial planner math — what you must understand
You'll implement this as your comparison baseline. Know the jerk formula cold:

Math reference · quintic polynomial jerk
# Quintic polynomial: pos(t) = a0 + a1*t + a2*t² + a3*t³ + a4*t⁴ + a5*t⁵
# Jerk is the 3rd time derivative:
# jerk(t) = 6*a3 + 24*a4*t + 60*a5*t²
# 
# Coefficients a0..a5 are solved analytically from 6 boundary conditions:
# pos(0)=p0, vel(0)=v0, acc(0)=0  ← start state
# pos(T)=pf, vel(T)=0, acc(T)=0   ← end state (stopped)
#
# The polynomial planner minimises jerk analytically.
# Your SNN must LEARN to achieve a similar result through STDP timing.

import numpy as np

def quintic_coeffs(p0, pf, v0, T):
    """Solve for quintic polynomial coefficients."""
    a0, a1, a2 = p0, v0, 0.0
    M = np.array([[T**3, T**4, T**5],
                  [3*T**2, 4*T**3, 5*T**4],
                  [6*T, 12*T**2, 20*T**3]])
    b = np.array([pf - a0 - a1*T, 0 - a1, 0])
    a3, a4, a5 = np.linalg.solve(M, b)
    return [a0, a1, a2, a3, a4, a5]

def compute_jerk(coeffs, t):
    a0, a1, a2, a3, a4, a5 = coeffs
    return 6*a3 + 24*a4*t + 60*a5*t**2

model.py · ANN vs SNN skeleton for MNIST
import snntorch as snn
import torch.nn as nn

class SimpleSNN(nn.Module):
    """2-layer LIF network for MNIST. Validates your SNN setup."""
    def __init__(self, beta=0.9):
        super().__init__()
        self.fc1  = nn.Linear(784, 512)
        self.lif1 = snn.Leaky(beta=beta)
        self.fc2  = nn.Linear(512, 256)
        self.lif2 = snn.Leaky(beta=beta)
        self.fc3  = nn.Linear(256, 10)

    def forward(self, x, num_steps=25):
        mem1 = mem2 = self.lif1.init_leaky()
        spike_count = 0
        for step in range(num_steps):
            cur1 = self.fc1(x)
            spk1, mem1 = self.lif1(cur1, mem1)
            cur2 = self.fc2(spk1)
            spk2, mem2 = self.lif2(cur2, mem2)
            spike_count += spk1.sum() + spk2.sum()
        out = self.fc3(spk2)
        return out, spike_count   # spike_count is your energy proxy

evaluate.py · 4-metric logging template
import numpy as np

def compute_jerk_series(positions, dt=0.02):
    """Numerical 3rd derivative of position array."""
    vel  = np.gradient(positions, dt)
    acc  = np.gradient(vel, dt)
    jerk = np.gradient(acc, dt)
    return np.max(np.abs(jerk))   # peak jerk scalar

def oscillation_amplitude(positions, stop_idx, window=50):
    """RMS of position deviation after stop_idx."""
    tail = positions[stop_idx:stop_idx + window]
    return np.sqrt(np.mean((tail - tail.mean())**2))

def log_episode(controller_name, positions, spike_count, flop_count):
    metrics = {
        'controller':  controller_name,
        'peak_jerk':   compute_jerk_series(positions),
        'endpoint_err': abs(positions[-1] - 0.0),    # target = center
        'spike_count': spike_count,
        'flops':       flop_count,
        'osc_amp':     oscillation_amplitude(positions, stop_idx=-50),
    }
    return metrics
The SNN controller: LIF + STDP architecture (Weeks 6–8, overlapping)
This is your actual research contribution. The architecture has four components — understand each one before coding it:

Layer	What it does	How it's trained	Key hyperparameters
Input layer	Converts cart velocity crossings → ON/OFF spike pairs	No training — deterministic encoding	Threshold (0.1 default), dead zone width
Hidden LIF layers (2–3)	Extract temporal features from the spike stream	Surrogate gradient backprop with FastSigmoid	β (decay), threshold, num_steps (25 default)
STDP timing layer	Learns WHEN to fire deceleration commands based on trajectory history. Your novel contribution	Hebbian STDP update rule — NOT gradient descent	A+, A−, τ+ (20ms), τ− (20ms), learning rate
Output layer	Torque/force command decoded from spike rate	Rate decoding — average spikes over time window	Decode window length, output scaling factor
model.py · STDP update rule
import torch

def stdp_update(weights, pre_spikes, post_spikes,
               A_plus=0.01, A_minus=0.01,
               tau_plus=20.0, tau_minus=20.0, dt=1.0):
    """
    Spike-Timing Dependent Plasticity weight update.
    
    If pre fires BEFORE post  → strengthen synapse (causal, A_plus)
    If pre fires AFTER post   → weaken synapse (anti-causal, A_minus)
    
    This is the biological learning rule. Not gradient descent.
    The timing window (tau) controls how far apart spikes can be
    and still affect each other. 20ms is biologically plausible.
    """
    dW = torch.zeros_like(weights)
    
    for t_pre, spk_pre in enumerate(pre_spikes):
        for t_post, spk_post in enumerate(post_spikes):
            if spk_pre > 0 and spk_post > 0:
                delta_t = (t_post - t_pre) * dt
                if delta_t > 0:   # pre before post: LTP
                    dW += A_plus * torch.exp(
                        torch.tensor(-delta_t / tau_plus))
                else:               # post before pre: LTD
                    dW -= A_minus * torch.exp(
                        torch.tensor(delta_t / tau_minus))
    return weights + dW
!
Budget Week 8 as a STDP debugging week. The learning window parameters (A+, A−, τ+, τ−) need careful tuning. Start with A+=A−=0.01 and τ+=τ−=20ms. If the STDP layer won't converge, fall back to surrogate-only — STDP becomes "future work" and you still have a paper.

The 100-episode runner — implement this in train.py
train.py · experiment runner
import gymnasium as gym
import pandas as pd
from evaluate import log_episode

def run_experiment(controller, controller_name, n_episodes=100):
    env = gym.make('CartPole-v1')
    results = []
    
    for ep in range(n_episodes):
        obs, _ = env.reset(seed=ep)    # fix seed for reproducibility
        positions, spike_counts = [], []
        done = False
        
        while not done:
            action, spike_count = controller(obs)
            obs, reward, terminated, truncated, _ = env.step(action)
            positions.append(obs[0])   # cart position
            spike_counts.append(spike_count)
            done = terminated or truncated
        
        metrics = log_episode(
            controller_name, positions,
            sum(spike_counts), flop_count=None
        )
        results.append(metrics)
        if ep % 10 == 0: print(f"Episode {ep}/100 done")
    
    env.close()
    df = pd.DataFrame(results)
    df.to_csv(f"outputs/{controller_name}_results.csv", index=False)
    return df

import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

def plot_jerk_comparison(dfs, names):
    """Figure 1: Box plot of peak jerk across 100 episodes, all controllers."""
    fig, ax = plt.subplots(figsize=(8, 4))
    data = [df['peak_jerk'].values for df in dfs]
    ax.boxplot(data, labels=names)
    ax.set_ylabel('Peak Jerk (m/s³)')
    ax.set_title('Jerk Comparison: 100 episodes each')
    plt.tight_layout()
    plt.savefig('outputs/fig1_jerk_comparison.pdf')

def plot_energy_tradeoff(dfs, names):
    """Figure 2: Scatter — FLOPs/step vs peak jerk. The key tradeoff plot."""
    fig, ax = plt.subplots(figsize=(6, 5))
    colors = ['#c8440a', '#1a6b5e', '#4a3d8c']
    for df, name, c in zip(dfs, names, colors):
        ax.scatter(df['flops'].mean(), df['peak_jerk'].mean(),
                  label=name, color=c, s=120, zorder=5)
        ax.errorbar(df['flops'].mean(), df['peak_jerk'].mean(),
                   xerr=df['flops'].std(), yerr=df['peak_jerk'].std(),
                   color=c, alpha=0.4)
    ax.set_xlabel('FLOPs per step (lower = more efficient)')
    ax.set_ylabel('Peak Jerk (lower = smoother)')
    ax.legend()
    plt.tight_layout()
    plt.savefig('outputs/fig2_energy_tradeoff.pdf')

Math & Key Equations Reference Sheet
The equations you need to know cold. Referenced in your Method section. Derivable from first principles if asked by reviewers.

Name	Equation	What it means in your work
LIF membrane	τ·dV/dt = −V + I(t)	Voltage leaks toward 0, driven by input current I. When V > V_th, spike fires and V resets
Discrete LIF (snnTorch)	V[t+1] = β·V[t] + I[t]·(1−s[t])	β is your decay parameter (0–1). s[t]=1 when spike fires. This is what you tune
STDP (potentiation)	ΔW = A+ · exp(−Δt/τ+), Δt>0	Pre fires before post: synapse strengthens. Δt is the time difference between spikes
STDP (depression)	ΔW = −A− · exp(Δt/τ−), Δt<0	Post fires before pre: synapse weakens. Together LTP+LTD shape the timing window
Jerk	J(t) = d³x/dt³ = ẍ̇	3rd time derivative of position. Your core metric. Numerically: np.gradient(np.gradient(np.gradient(pos)))
Quintic jerk	J(t) = 6a₃ + 24a₄t + 60a₅t²	The polynomial baseline jerk function. Coefficients solved analytically from boundary conditions
Surrogate gradient	∂s/∂U ≈ σ'(U) = σ(U)·(1−σ(U))	Approximate gradient of spike function. Makes SNN trainable with backprop despite non-differentiable spikes
Spike count (energy proxy)	E ∝ Σₜ Σₙ sₙ(t)	Total spikes fired across all neurons and timesteps. Proportional to synaptic operations = energy cost
